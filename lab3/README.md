# Лабораторная №3 — Пороговая обработка изображений (C++ + Qt)

**Десктопное GUI-приложение** для пороговой обработки изображений.
Реализованы три метода: **Оцу**, **Итеративный**, **Адаптивный**.

## Задание

Реализовать три метода пороговой обработки:
1. Глобальная — 2 метода на выбор (Оцу и Итеративный).
2. Адаптивная — локальный порог для каждой области.

## Реализованные методы

### 1. Метод Оцу (глобальный)

Автоматический выбор оптимального порога по гистограмме.
Перебирает все пороги 0–255, выбирает тот, при котором
**межклассовая дисперсия** максимальна.

**Хорошо работает:** на чётких двумодальных изображениях.

### 2. Итеративный метод (глобальный)

Начинает со среднего значения яркости и пошагово уточняет порог.
**Отличие от Оцу:** быстрее, но результат близок.

### 3. Адаптивный метод (локальный)

Для **каждого пикселя** вычисляет **свой** порог по локальному окну 15×15.

**Хорошо работает:** на изображениях с **неравномерным освещением**, тенями, сложным фоном.

## Технологии

- **C++17** — язык.
- **Qt 6** — GUI.
- **CMake** — система сборки.
- **MinGW-w64** — кросс-компиляция для Windows.

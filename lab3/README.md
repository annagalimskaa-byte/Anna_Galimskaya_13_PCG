# Лабораторная №3 — Пороговая обработка изображений

Веб-приложение для пороговой обработки изображений.

## Методы

- Оцу (глобальный)
- Итеративный (глобальный)
- Адаптивный

## Технологии

- Python 3.11 + Flask
- NumPy, SciPy
- Pillow

## Локальный запуск

pip install -r requirements.txt
python app.py

Открыть: http://127.0.0.1:5000

### Лабораторная №1 — Цветовые модели

**Описание:** Desktop-приложение для работы с цветовыми моделями RGB, CMYK, HLS, XYZ и Lab.

**Технологии:** Python 3, Tkinter, unittest, PyInstaller

**Папка:** [lab1/](./lab1)

---

### Лабораторная №2 — Парсинг метаданных изображений

**Описание:** Приложение для извлечения метаданных из 6 графических форматов (BMP, PNG, JPEG, GIF, TIFF, PCX) без сторонних библиотек.

**Технологии:** C++17, Qt 6, CMake, MinGW-w64

**Папка:** [lab2/](./lab2)

**Особенности:**

- Ручной побайтовый парсинг
- Многопоточность (ThreadPool)
- GUI на Qt 6
- `.exe` под Windows

---

### Лабораторная №3 — Пороговая обработка изображений

**Описание:** Приложение для пороговой обработки изображений.
Реализованы методы: Оцу, Итеративный, Адаптивный.

**Реализовано в двух версиях:**

1. **Десктопное GUI на C++ с Qt** — папка [lab3/](./lab3)
   - Работает на macOS, Linux, Windows
   - Загрузка изображений, выбор метода, сохранение результата

2. **Веб-приложение на Python с Flask** — папка [lab3_web/](./lab3_web)
   - **🌐 Живое приложение:** [https://anna-galimskaya-13-pcg.onrender.com](https://anna-galimskaya-13-pcg.onrender.com)
   - Работает в любом браузере — включая Windows XP
   - Не требует установки

**Реализованные методы:**

- **Оцу** — глобальный порог по межклассовой дисперсии
- **Итеративный** — глобальный порог через уточнение
- **Адаптивный** — локальный порог для каждой области (окно 15×15)

### Лабораторная №4 — Базовые растровые алгоритмы

**Описание:** Десктопное GUI-приложение для иллюстрации 4 базовых растровых алгоритмов.

**Реализованные алгоритмы:**
- **Пошаговый** — простой, с дробными числами.
- **Алгоритм ЦДА (DDA)** — цифровой дифференциальный анализатор.
- **Алгоритм Брезенхема (линия)** — только целые числа.
- **Алгоритм Брезенхема (окружность)** — через 1/8 + симметрию.

**Технологии:** C++17, Qt 6, CMake

**Папка:** [lab4/](./lab4)

**Особенности:**
- Рисование линий и окружностей на холсте
- Сетка и оси координат
- Замер времени каждого алгоритма
- Сравнение производительности

**Временные характеристики (линия 0,0 → 100,100):**
- Пошаговый: ~157 мкс
- ЦДА: ~90 мкс
- Брезенхем (линия): ~134 мкс
- Брезенхем (окружность): ~81 мкс
